Preface

How to read this notebook

day numbers order the pages; the dates are the dates on record

Ratul Hasan Ruhan is a software engineer working across mobile, web, desktop, embedded systems, and core computer science. He started with Android development and expanded into cross-platform engineering, applied AI/ML, systems programming, and infrastructure.

He is especially interested in how software systems are designed, how components interact, and how research ideas translate into reliable, real-world applications. He values clarity, maintainability, and thoughtful engineering.

He builds technology for Bangla speakers and is the creator of Ojogor, the first Bengali programming language. He is based in Dhaka, Bangladesh.

Day 1
Oct 2025

Day 1 · Recorded October 2025

Ojogor (অজগর)

the first Bengali programming language

Ojogor is an interpreter for a Bengali programming language: programs can be written and run with Bengali syntax. It is meant to make programming accessible to Bengali speakers, especially beginners.

The project received the Bangladesh ICT & Innovation Award 2025 (October 2025), awarded by the Bangladesh ICT & Innovation Network (BIIN).

The CCRP paper

preprint on ResearchGate — not a society journal

Caller Collision Resolution Protocol (CCRP): Bridging Simultaneous Call Attempts in Real-World Telephony ↗

Preprint, October 2025 · DOI 10.13140/RG.2.2.26499.98081 · ResearchGate

The paper introduces CCRP, a framework for mutual call collisions — the telephony case in which two parties call each other at the same time and each receives a busy signal.

Research focus

  • Computer systems and software architecture
  • Applied AI / ML in real-world systems
  • Human-centered and localized computing
  • Programming languages and developer tooling
